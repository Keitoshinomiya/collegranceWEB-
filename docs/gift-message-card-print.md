# メッセージカードの印刷手順（選べる3本ギフトセット）

対象: ギフトセットを含む注文（Slack #collegrance-発送 の通知に「🖨 メッセージカードを印刷」リンクが出る）

## 用意するもの
- 用紙: 名刺サイズ（91×55mm）A4 10面のマルチカード（2列×5段・ミシン目）
- プリンター: Canon G3090（カラー）

## 毎回の手順
1. Slack の発送通知の「🖨 メッセージカードを印刷」を開く（文面・贈り主は注文から自動で入る）
2. 「1枚目を刷る面」で、用紙の**まだ使っていない面**の番号を押す（1=左上・2=右上・3=2段目左 … 10=右下）
3. 「印刷する」→ 印刷ダイアログで **倍率100%（実際のサイズ）・余白なし・ヘッダー/フッターなし・片面** を確認
4. マルチカードを表向きにセットして印刷 → ミシン目で切り離してギフトセットに同梱
5. 複数セットの注文は、続きの面に自動で並ぶ（10面を超えたら2枚目の用紙）

## 初回だけ：位置合わせ
1. 印刷ページの「位置合わせテスト」を開き、**普通紙**に印刷（10面ぶんの枠線と十字が出る）
2. マルチカードと重ねて光に透かし、枠とミシン目がずれていないか確認
3. ずれていたら「位置の微調整」に mm で入力（右へ +／左へ −、下へ +／上へ −）→ もう一度テスト
4. 値はそのPCのブラウザに記憶される（別のPC・別のブラウザでは再入力）

## 困ったとき
- 「このリンクは開けません」… Slack のリンクを最後までコピーできていない。通知から開き直す
- 「まだ決済が完了していません」「期限切れ」の表示 … その注文は発送しない（Stripeで確認）
- 文字が小さすぎる・はみ出す … 文面の長さに合わせて自動で縮む（最大60文字）。気になれば代表に相談
- 用紙の余白が違うメーカーの場合 … URL の末尾に `&mx=左余白mm&my=上余白mm` を付ける（既定 14 / 11）

仕組み: `netlify/functions/gift-card.js`（印刷ページ）・`netlify/lib/gift-card.js`（リンクの鍵）・`netlify/functions/stripe-webhook.js`（Slackのリンク）
